# 個別銘柄分析ダッシュボード ユーザーガイド

## 概要
個別銘柄分析ダッシュボードは、特定の株式銘柄に関する基本情報から、テクニカル分析、ファンダメンタル分析、そしてリスク管理指標に至るまで、多角的な情報を1画面で俯瞰できる機能です。

## 画面構成 (Bento-box レイアウト)
画面は以下のカード（Bento-box）で構成されています。

### 1. 銘柄基本情報
- 銘柄名、コード、市場、業種、現在の株価と時価総額を表示します。

### 2. 株価チャート (日足)
- **ローソク足**: 日々の値動き（始値・高値・安値・終値）を示します。（緑＝陰線、赤＝陽線 ※日本式）
- **出来高チャート**: 画面下部に配置され、日々の取引量を示します。
- **移動平均線 (SMA)**: 25日、75日、200日の3本の移動平均線を描画し、短期〜長期のトレンドを視覚的に把握できます。
- **指標トグル（近日実装予定）**: MACD、ボリンジャーバンド、ATR損切ラインなどの表示を切り替えることができます。

### 3. モメンタム指標
短期から中期における株価の勢い（モメンタム）を示します。
- **5日/20日騰落率**: 直近の株価パフォーマンス。
- **52週高値距離**: 過去1年間の最高値から現在どれだけ下落しているかを示します。

### 4. テクニカル指標
チャート形状から算出される客観的な数値です。
- **25日線乖離率**: 現在の株価が25日移動平均線から何%離れているかを示します。高すぎると過熱、低すぎると売られすぎの目安となります。
- **RSI (14日)**: 買われすぎ・売られすぎを示すオシレーター指標。一般に70以上で買われすぎ、30以下で売られすぎと判断されます。
- **MACD**: 短期と中期の移動平均の差分。トレンドの方向性や転換点を捉えるのに役立ちます。

### 5. リスク管理情報
投資における損失リスクを管理するための指標です。
- **ATR (Average True Range)**: 1日あたりの平均的な値幅（ボラティリティ）。この値が大きいほど値動きが激しいことを示します。
- **2ATR 損切ライン**: 現在の株価から「ATRの2倍」を引いた価格。通常のノイズによる値動きを許容しつつ、トレンド転換を検知して損切りするための目安ラインです。
- **最大ドローダウン**: 過去最高値からの最大下落率。その銘柄の持つ潜在的なリスク（最悪のケース）を示します。

### 6. バリュエーション (株価指標)
企業価値に対して株価が割安か割高かを判断する指標です。
- **PER (株価収益率)**: 1株あたり利益(EPS)に対して株価が何倍まで買われているかを示します。
- **PBR (株価純資産倍率)**: 1株あたり純資産に対して株価が何倍まで買われているかを示します。
- **ROE (自己資本利益率)**: 自己資本を使ってどれだけ効率よく利益を上げているかを示す収益性の指標です。
- **配当利回り**: 現在の株価に対して、年間でどれだけの配当金を受け取れるかの割合です。

### 7. 決算情報・業績財務
企業のファンダメンタル（基礎的条件）の健全性や成長性を示します。
- **決算日**: 直近の決算発表日。
- **売上・営利成長率**: 前年同期比での成長率。
- **決算後上昇**: 決算発表後に株価がどの程度反応したか（サプライズ度合い）を示します。

## 8. AI アナリストレポート (Gemma3:12B)
ローカル稼働のAI（Gemma3:12B）が決算説明資料PDFを読み込み、証券アナリストの視点で解析したサマリーを表示します。
- **当期実績 (Current Performance)**: 当期の強み・弱み、好調要因や懸念事項を具体的な数値を交えて統合評価します。
- **次期見通し (Future Guidance)**: 会社側の次期業績見通しや、直面している経営課題、未来へのリスク要因を提示します。
- **前回比較 (Report Comparison)**: 前回（3Q等）の決算資料と比較し、新たに浮上した懸念やトーンの変化（不確実性の高まりなど）を鋭く抽出します。
- **AI 総括 (AI Comment)**: アナリストとしての総合的な評価と今後の展望を総括します。

## 9. 分類情報 (GICS産業分類) の確認と手動指定

各企業ページには、世界標準の産業分類基準である **GICS（世界産業分類基準）** に基づく4階層の分類が表示されます。

- **大分類 (主幹テーマ / セクター)**: 例: 一般消費財・サービス、情報技術
- **中分類 (産業グループ)**: 例: 自動車・自動車部品、ソフトウェア・サービス
- **小分類 (産業)**: 例: 自動車用部品、ソフトウェア
- **細分類 (サブインダストリー)**: 例: 自動車用部品・装置、アプリケーション・ソフトウェア

### 細分類の変更と自動逆算
AIによる自動判定結果をユーザーが手動で微調整・確定することができます。

1. 「分類情報」カード右上の **「細分類を変更」** ボタン（または「細分類」テキスト）をクリックします。
2. 表示されるモーダルから、全149件のGICS細分類をコード・名称で検索・選択します。
3. 候補をクリックして選択した瞬間に、**小分類・中分類・大分類が完全自動逆算**され、画面表示が即座に切り替わります。
4. 同時にバックエンドAPI経由でデータベース（`equities_master`, `stocks`, `sepa_metrics`）へ即座に永続化され、監査ステータスが `OK`（承認済み）へと更新されます。
