# マーク・ミネルヴィニ SEPA (Specific Entry Point Analysis) ユーザーガイド

本システムは、米国の全米投資競技チャンピオンであるマーク・ミネルヴィニ（Mark Minervini）の投資手法 **SEPA（Specific Entry Point Analysis: 特定エントリーポイント分析）** を、日本株市場の特性（四半期累計開示、株式分割、IPOバイアス）に合わせて厳密に実装したスクリーニング＆分析基盤です。

---

## 1. SEPAの5大コア要素

SEPAは、以下の5つの柱がすべて揃った銘柄のみを厳選します：

1. **トレンド（Trend Template）**: Stage 2（本格上昇トレンド）にある銘柄のみに対象を限定。
2. **ファンダメンタルズ（Fundamentals）**: 爆発的なEPS・売上成長、利益率の改善、黒字転換。
3. **カタリスト（Catalysts）**: 新規事業、新製品、法改正などの株価急騰の起爆剤（Docling AI連携）。
4. **エントリーポイント（Entry Point / VCP）**: 値幅と出来高が収縮したピボットポイントでの最小リスクエントリー。
5. **エグジット（Exit / Risk Management）**: 最大-7%〜-8%での無条件損切りと、リスクリワード比1:2〜1:3での利益確定。

---

## 2. トレンドテンプレート（8つの必須条件）

上昇局面（Stage 2）にある銘柄を機械的に判定する基準です：

1. **株価 > 150日SMA かつ 株価 > 200日SMA**
2. **150日SMA > 200日SMA**
3. **200日SMAが上向き（緩和条件）**
   - 22日最小二乗法線形回帰スロープ $Slope_{22d} > 0$
   - かつ $SMA200_{\text{today}} \ge SMA200_{22d}$
   - かつ $SMA200_{\text{today}} \ge SMA200_{10d}$
   - （※5ヶ月上向きは追加ボーナスとして判定）
4. **50日SMA > 150日SMA かつ 50日SMA > 200日SMA**
5. **株価 > 50日SMA**
6. **株価 >= 52週最安値 + 25%**（大底から強力にリバウンドしていること）
7. **株価 >= 52週最高値 - 25%**（最高値から25%以内の高値圏にあること）
8. **RS（Relative Strength）レーティング >= 70**（市場上位30%以内の強さ）

### IPO銘柄バイパス（上場250営業日未満）
上場後1年未満の急成長株は200日線が存在しないため、以下の緩和条件で合否を判定します：
- 株価 > 50日SMA（または20日SMA）
- 最高値から25%以内 かつ 最安値から+25%以上
- 画面上では `[IPO]` バッジが付与されます。

### 掲載日（Stage 2突入日）の遡及算出
Stage 2条件を満たした銘柄は、過去日足を直近から過去へ遡り（Backwards Walk）、8条件を満たし続けた起点となる「突入日（掲載日）」と経過日数を自動算出します。リストから一時脱落した後に再突入した場合でも、最新の突入日が表示されます。

## 3. 日本株独自動的加重RS（Relative Strength）レーティング

東証上場全銘柄（約4,200銘柄）を母集団として、株価パフォーマンスを **1〜99のパーセンタイル** で数値化した指標です（99が市場最強、50が市場平均）。

### 期間別動的加重方式
- **通常銘柄（252日以上）**: $RS = 0.4 \times R_{63d} + 0.2 \times R_{126d} + 0.2 \times R_{189d} + 0.2 \times R_{252d}$
- **IPO・新興銘柄（63〜251日）**: 存在する日数に応じて短期間の騰落率に自動加重。画面上では `[85*]` のようにアスタリスク付きのオレンジ色で **擬似RS（短期間加重）** であることを明示します。
- **上場廃止銘柄の自動除外**: 市場全体の最新取引日から10カレンダー日以上データが更新されていない銘柄は、母集団から自動除外されます。

## 4. 四半期単体ファンダメンタルズと累計開示の罠

日本企業は決算短信を四半期累計（Q1, Q2累計, Q3累計, FY）で開示するため、単なるEPSの合算は二重加算を引き起こします。本システムでは **3ヶ月単体値** を厳密に逆算し、前年同期比（YoY）を算出しています。

### 黒字転換・赤字のステータス管理
前年同期が赤字（$\le 0$）の場合、通常の割り算では符号逆転の計算不能が生じるため、以下のステータスコードを付与します：
- **`TURNAROUND`（黒字転換）**: 前年赤字から当期黒字へ急回復した最強の買いシグナル。
- **`LOSS_REDUCTION`（赤字縮小）**: 赤字幅が縮小している改善局面。
- **`EXPLOSIVE_GROWTH`**: EPS+300%以上かつ売上高+10%以上の大成長。
- **`⚠️ 会計調整疑い`**: 売上が伸びていない（+10%未満）のにEPSだけ急増している期末調整ノイズへの警告フラグ。

## 5. VCP（ボラティリティ収縮パターン）とピボット監視

ミネルヴィニが提唱する **VCP（Volatility Contraction Pattern）** は、株価の振れ幅（ボラティリティ）と出来高が左から右へ段階的に縮小し、売り手が枯渇した瞬間（ピボット）を捉える手法です。

- **ベース期間高値（Base High）**: 直近2〜65営業日の終値ベース最高値（ベース全体のレジスタンス。チャート上は橙色点線で表示）。
- **真のピボット（True Pivot Price）**: 直近2〜15営業日前（ハンドル形成部）の終値最高値（ブレイクアウト監視ライン。チャート上は金色破線で表示）。
- **ピボット健全性ガード**: ハンドル部ピボットがベース高値から15%以上深く押し込んでいる場合（$pivot\_price < base\_high \times 0.85$）は安値圏の偽ピボットとして除外。
- **セットアップ圏内**: ピボット価格から **-3.0% 〜 0.0%** の直前水準。
- **ブレイクアウト**: ピボット価格を上回り（0%〜+5%）、出来高がドライアップから急増した瞬間。
- **値幅収縮（ATR Contraction）**: ハンドル部ATR(5) / ベース初期ATR(20) < 0.70（直近の値幅が初期の70%以下に収縮）。
- **出来高枯渇（Volume Dry-Up: VDU）**: 直近5日平均出来高 / 50日平均出来高 < 0.60（出来高が急激に薄くなっている状態）。

※波の収縮回数（3T, 4T等）やハンドルの形状は人間の目による総合判断が最も高精度であるため、VCPタブでは銘柄をクリックすると即座に右側に日足チャートが展開され、目視で波の形状を確認できるよう設計されています。

## 6. リスク管理と目標価格（1:2 / 1:3）

いかに素晴らしい銘柄であっても、相場環境や誤審による下落は避けられません。SEPAでは **厳格な損切り** が勝率よりも重要視されます：

- **最大損切り**: 買値から **-7%〜-8%**（または2 ATR）に必ず逆指値を置く。
- **目標価格**: 損切り幅の2倍（リスクリワード 1:2）および3倍（1:3）に設定し、利益確定を行う。
- 個別銘柄診断画面の「リスク管理シミュレーター」にて、買付株価を入力するだけで自動算出されます。
