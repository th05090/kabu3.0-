# 統合ウォッチリスト（Watchlist）利用者ガイド

## 1. 概要とトレードにおける意義

### 1.1 なぜウォッチリストが必要なのか？
マーク・ミネルヴィニやウィリアム・オニールのトレード手法において、**「利益の8割は事前の監視リスト（Watchlist）の質で決まる」** と言われます。

相場が動いてから慌てて銘柄を探すのではなく、週末や前夜のスクリーニングで：
1. **機関投資家の資金が集中しているセクター（GICS流入レーダー）**
2. **Stage 2 上昇トレンドにある銘柄（SEPAトレンドテンプレート）**
3. **ボラティリティが収縮しピボットを形成しつつある銘柄（VCP候補）**
4. **主要サポートラインまで調整してきた先導株（21EMA/50SMA押し目）**

をあらかじめウォッチリストに登録しておき、**「買いのトリガー（前日高値突破・ピボットブレイク）が引かれた瞬間に迷わずエントリーする」** のが勝ち続ける投資家の鉄則です。

本システムでは、スクリーナー・SEPA・セクター資金流入・個別銘柄詳細のすべての画面から、**ワンクリック（★）で瞬時に登録・解除**でき、専用画面（`/watchlist`）で日足チャートを見ながら一括監視・追跡できます。

---

## 2. コア機能と特徴

### 2.1 登録元ソースの自動タグ付け（フォルダ管理不要）
複雑なフォルダ作成やタブ分けの手間を完全になくすため、**「どの画面で星（★）を押したか」** をシステムが自動的にタグ付けします。

| 登録元バッジ | 発生画面 | 主な監視目的・投資的意味 |
| :--- | :--- | :--- |
| **`[SEPA]`** | SEPA分析画面（`/sepa`） | VCPセットアップ、ピボットブレイク直後、21EMA/50SMA押し目反発の監視。 |
| **`[スクリーナー]`** | メインスクリーナー（`/`）<br>および個別銘柄ページ（`/stocks/[ticker]`） | スクリーナー一覧および詳細分析からの注目株・好業績株・新高値ブレイク候補の監視。 |
| **`[セクター流入]`** | GICSセクター資金流入ドロワー | 機関投資家のバスケット買いが入っている最強業種の先導株の監視。 |
| **`[手動追加]`** | ウォッチリスト画面の入力バー | 気になるティッカー（4桁コード）を直接指定して即座に追加。 |

画面上部のフィルターチップ（`[すべて]` `[SEPA]` `[スクリーナー]` `[セクター流入]`）をクリックするだけで、目的別の銘柄群を瞬時に絞り込めます。

### 2.2 登録日＆登録時株価からのパフォーマンス追跡
星（★）を押した瞬間の **「登録日」** と **「登録時終値」** がDBに自動記録されます。
- **登録来騰落率（%）**:
  $$\text{SinceAddedPct} = \frac{\text{現在株価} - \text{登録時株価}}{\text{登録時株価}} \times 100$$
- 「いつ登録して、そこから上がったのか（プラス緑）下がったのか（マイナス赤）」が常時一目で分かります。

### 2.3 左右2ペイン・チャートプレビュー連動レイアウト
ウォッチリスト画面（`/watchlist`）は、実戦のスピード感を重視した左右2ペイン構成です：
- **左ペイン（一覧テーブル）**:
  - 銘柄コード、企業名、登録元バッジ、現在株価、前日比、登録日＆登録時株価、登録来騰落率、SEPA状態バッジを表示。
  - 行をクリックするだけで、右ペインが即座に切り替わります。
- **右ペイン（クイック詳細プレビュー ＆ チャート）**:
  - **インライン編集メモ**: 「21EMA反発待ち」「3,000円抜けで打診買い」などのトレードシナリオを自由に書き込み、即座に自動保存可能。
  - **日足チャート (`SepaPriceChart`)**: 21日EMA（紫）、50日SMA（緑）、150日SMA（シアン）、200日SMA（赤）、ピボットライン（金色破線）、および下部出来高バー上に「50日出来高(トリム)」（アンバー色）を描画。SEPA判定と100%一致する平時出来高基準を視覚化し、画面遷移することなくチャート形状・サポートライン・出来高枯渇（VDU）を即座に目視確認できます。
  - **詳細分析リンク**: さらに深い財務やAI決算分析、適時開示PDFを確認したい場合は、右上の「詳細分析」ボタンからワンクリックで個別分析ダッシュボード（`/stocks/[ticker]`）へ遷移できます。

## 3. 実戦での操作フロー（おすすめのルーティン）

1. **週末・引け後の候補選定**:
   - SEPA画面の「Stage 2 ＋ 21EMA押し目」や「ブレイク後初回押し目」をチェックし、良型の銘柄に「★」を押す。
   - セクター資金流入画面で `⚡📊 初動＋トレンド一致` にある最強業種を開き、ドロワー内の先導株に「★」を押す。
2. **ウォッチリストでの整理・シナリオ記入**:
   - サイドバーの「ウォッチリスト」を開く。
   - 各銘柄のチャートプレビューを見ながら、右側のメモ欄に**「仕掛けポイント（例: 21EMA反発・前日高値上抜け）」「損切りライン」「利食い目標」**を記入する。
3. **翌朝の寄り付き・ザラ場チェック**:
   - 地合いインジケーター（ヘッダー）が 🟢良好 または 🟡調整警戒 であることを確認。
   - ウォッチリストのメモで定めたシナリオ通りに反発・ブレイクした銘柄にのみエントリーする。
