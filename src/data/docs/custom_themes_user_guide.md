# マイテーマ管理機能 ユーザーガイド

## 概要
本システムでは、動的テーマ検索や個別銘柄分析で見つけた有望な銘柄群を、ユーザー独自の「マイテーマ（Custom Themes）」として保存・管理することができます。
保存されたテーマはポートフォリオ構築のアイデア帳や、一括バックテスト・モニタリングのベースとして活用されます。

## 1. マイテーマの作成と保存
テーマ検索タブ（Theme Search）にて検索を行い、リストアップされた銘柄の中から有望なものにチェックボックスでチェックを入れます。
「選択した銘柄でテーマを保存」ボタンを押すことで、任意の名前をつけて新しいマイテーマとして保存できます。
* AIが自動算出したハイブリッド検索スコア（RRFスコア）も同時に保存され、どの銘柄がそのテーマの中核（ド本命）なのかを後から振り返ることができます。

## 2. マイテーマ一覧と構成銘柄の確認
「マイテーマ（Custom Themes）」タブを開くと、保存したテーマの一覧が表示されます。
一覧では各テーマの「登録銘柄数」や「トップ3銘柄」がひと目で確認できます。

テーマの行を展開すると、構成銘柄の詳細リストが表示されます。
ここでは、以下の操作が可能です。

### 銘柄の手動追加
「このテーマにはあの銘柄も入れておきたい」という場合、リスト上部の入力欄にティッカー（銘柄コード）を打ち込むことで、手動でピンポイントに銘柄を追加できます。
追加された銘柄は即座にデータベースに保存され、テーマの一部として組み込まれます。

### 単一銘柄の削除
構成銘柄リストの右側にあるゴミ箱アイコンをクリックすると、その銘柄をテーマから除外できます。

## 3. マイテーマの一括管理（バルク操作）
不要になった過去のテーマや、実験的に作成したテーマが溜まってきた場合、一覧の左側にあるチェックボックスを使って複数選択し、**「一括削除（Bulk Delete）」**を実行することができます。
内部的にはトランザクション処理により安全に複数テーマと構成銘柄がDBから消去されます。

## 4. 今後の活用（ロードマップ）
作成したマイテーマは、将来的に以下の機能と連携する予定です。
* **ネットワークグラフ可視化**: テーマ内の銘柄同士がどのように関連しているかを視覚的に分析。
* **一括バックテスト**: テーマ全体を1つの仮想ファンドと見立てて、過去のパフォーマンスや暴落耐性をシミュレーション。
* **買いシグナルモニタリング**: テーマ内の銘柄群にテクニカルな買いシグナル（MACDゴールデンクロス等）が点灯した際のアラート通知。
