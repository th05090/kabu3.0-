# GICSセクター資金流入確認ツール 利用者ガイド

## 1. ツールの目的と基本コンセプト
機関投資家（年金基金、ヘッジファンド、運用会社など）の大口資金は、数億円〜数百億円規模に達するため、単一銘柄ではなく**同一セクター内の複数銘柄をバスケットで買い集める（Accumulation）** 傾向があります。
本ツールは、**GICS Industry（6桁分類・約74業種）** および **GICS Industry Group（4桁分類・約25業種グループ）** の2つの階層から、日足データから推計される資金シフトの兆候を機械的・客観的に炙り出すレーダーです。

- **母集団**: GICS分類済み全銘柄（監査ステータス `OK` および `ERROR` を含む約3,650社、ETF/REIT等を除く）。
- **分類切り替え**: 画面上部のトグルボタンで「業種（6桁）」と「業種グループ（4桁）」を即座に切り替え可能。それぞれの階層母集団内でスコアが再パーセンタイル正規化（0〜100点）されます。

## 2. 3層・11指標の投資的解釈

本ツールは「資金流入（原因）」と「株価上昇（結果）」を混同せず、以下の3段階の因果関係でセクターを多面的に評価します。

### Layer 1: 資金フロー (Capital Flow: 配点 40%)
*「市場のマネーがそのセクターに実際に吸い寄せられているか」を直接測定*
1. **売買代金シェア変化率 / 変化幅**:
   - 市場全体の総売買代金のうち、そのセクターに取引がどれだけ集中してきたか。
   - 相対変化率（%変化）と絶対変化幅（pt差）を 50:50 でブレンドすることで、ニッチ業種の急激な初動と巨大セクターへの巨額マネー流入を両立評価します。
2. **規格化 MFV (Money Flow Volume)**:
   - 日中の高値・安値に対する引け値の位置（$-1.0 \sim +1.0$）に売買高を掛け合わせ、業種の総売買代金で規格化した比率。
   - プラスなら引けにかけて買い上がられた「資金純流入」、マイナスなら上ヒゲや陰線で売られた「資金純流出」。
3. **グループ A/D レシオ**:
   - 出来高が増加した陽線日数 $\div$ (出来高が増加した陰線日数 $+ 1$)。
   - 上昇時に商いが膨らみ、調整時に商いが細る大口特有の買い集めリズムを測定。
4. **グループ CLV 中央値**:
   - 業種内全銘柄の当日 CLV（Close Location Value: $0.0 \sim 1.0$）の中央値。日中高値引けの度合いを外れ値なく捉えます。

### Layer 2: 内部構造 (Internal Breadth: 配点 35%)
*「入ってきた資金がセクター内の複数銘柄に波及しているか」を測定*
5. **セクター騰落ブレッドス**: 期間リターンがプラスの銘柄比率（%）。買いの裾野の広がり。
6. **等ウェイト vs 加重 Spread**: （等ウェイト騰落率）$-$（時価総額加重騰落率）。
   - プラスなら「大型株だけでなく中小型株も含めて広く買われている（理想的なバスケット買い）」。
   - ※相場全体が下落している局面では、大型株の急落による見せかけのプラスを排除するため評価を中立にクランプします。
7. **出来高急増陽線比率**: 50日平均出来高の1.5倍以上かつ陽線の銘柄比率。
8. **新高値銘柄比率**: 直近60営業日新高値を更新した銘柄比率。
9. **トレンド同期率**: 25日線および50日移動平均線を上回っている銘柄比率。

### Layer 3: モメンタム (Price Momentum: 配点 25%)
*「資金流入の結果として、株価にどう現れているか」を測定*
10. **超過RS ($\Delta$RS)**: セクター等ウェイト騰落率と市場全体等ウェイト騰落率の差（市場対比モメンタム）。
11. **Stage 2 ブレイク集中度**: 直近5営業日以内にベース新高値ブレイクアウトを達成した銘柄比率。

## 3. 総合スコアとMECEバッジの読み方

全業種母集団（$N \ge 5$）の中で各指標のパーセンタイルランクを合成後、最終スコアを再パーセンタイル化して 0〜100 点に均等配分しています。

| 状態バッジ | 判定条件 | 投資的な解釈 |
| :--- | :--- | :--- |
| **`🔥 強烈な資金流入`** | スコア 80点以上 ＆ 業種騰落 $> 0$ ＆ 超過RS $> 0$ | セクター上昇とTOPIXアウトパフォームが完全合致した最強の主役業種。 |
| **`📈 上昇（市場劣後）`** | スコア 80点以上 ＆ 業種騰落 $> 0$ ＆ 超過RS $\le 0$ | 業種自体は上昇しているが、相場全体の急騰にモメンタムが劣後している状態。 |
| **`⚖ 相対優位（地合い不良）`** | スコア 80点以上 だが 業種騰落 $\le 0$ | 全面安局面で下げ渋っているディフェンシブ・相対優位業種。安易な買いは慎重に。 |
| **`📈 資金流入の初期兆候`** | スコア 65〜79点 ＆ 業種騰落 $> 0$ ＆ 超過RS $> 0$ | 売買シェアや先行銘柄に資金集約の初期サインが見られる注目業種。 |
| **`⚖ 中立`** | スコア 45〜64点 | 市場平均並みの通常推移。 |
| **`📉 資金流出傾向`** | スコア 44点以下 | 商い縮小・ディストリビューション傾向。 |

## 4. ドリルダウンと個別株エントリーの特定手順

1. **業種行をクリック**:
   - テーブル内の気になる業種をクリックすると、右側から構成銘柄一覧（サイドドロワー）がスライドインします。
2. **最優先列のバッジを確認**:
   - **`🔥 反発トリガー`**: SEPA押し目条件を満たし、当日陽線かつ前日高値を超えた銘柄。**反発初動のエントリー検討候補**。
   - **`🚀 直近ブレイク`**: 直近5営業日以内に新高値をブレイクした強勢銘柄。
   - **`★ 21EMA押し目` / `★ 50MA押し目`**: 支持帯テスト中の監視銘柄。
3. **ワークフロー**:
   - 「🔥強烈な資金流入」セクターを開き、その中で「🔥反発トリガー」が点灯している銘柄を狙うことで、強力なセクターの追い風を受けながら高勝率なエントリーが可能になります。
