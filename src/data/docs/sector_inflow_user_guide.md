# GICSセクター資金流入確認ツール 利用者ガイド

## 1. ツールの目的と基本コンセプト
機関投資家（年金基金、ヘッジファンド、運用会社など）の大口資金は、数億円〜数百億円規模に達するため、単一銘柄ではなく**同一セクター内の複数銘柄をバスケットで買い集める（Accumulation）** 傾向があります。
本ツールは、**GICS Industry（6桁分類・約74業種）** および **GICS Industry Group（4桁分類・約25業種グループ）** の2つの階層から、日足データから推計される資金シフトの兆候を機械的・客観的に炙り出すレーダーです。

本ツールは、**「⚡ 先行初動レーダー（初動検知）」** と **「📊 トレンド確認（事後確認）」** の2つの独立した視点をワンクリックで切り替え可能とし、さらに双方が合致した局面を **「相場の進行段階（3段階構造）」** として可視化します。

- **母集団**: GICS分類済み全銘柄（監査ステータス `OK` および `ERROR` を含む約3,650社、ETF/REIT等を除く、有効銘柄数 $N \ge 5$）。
- **完全同一の母集団**: 先行初動レーダーとトレンド確認ツールは、まったく同一のセクター配列・銘柄集合に対して同時にスコア・順位を算出しています。

## 2. 相場の進行段階（3段階ステータス）の読み方

本ツールは売買の断定を行うものではなく、セクターが現在「相場のどの進行段階にあるか」を客観的なバッジで表示します。

| 進行段階バッジ | 判定条件 | バックテスト実証値（20日後） | 投資的な解釈 |
| :--- | :--- | :---: | :--- |
| **`⚡📊 初動＋トレンド一致`** | 先行初動 Q1（上位20%）<br>＋ トレンド確認 Q1（上位20%） | **個別平均 +1.52%**<br>**週平均 +1.71%**<br>(95%CI: [+0.98, +2.07]%) | 初動シグナルが出た後、実際のトレンド形成も確認された最上位ステージ。最も高いリターンが観測された領域。 |
| **`⚡ 初動兆候`** | 先行初動 Q1 のみ | **個別平均 +1.18%**<br>**週平均 +1.08%**<br>(MAE: **-5.35%** 最も浅い) | トレンド形成には至っていないが、水面下の商い急増・逆行耐性などの初動兆候が出現。保有期間中の逆行幅が浅い。 |
| **`📊 トレンド確認`** | トレンド確認 Q1 のみ | **個別平均 +1.15%**<br>**週平均 +1.07%**<br>(MAE: -6.62%) | 価格・出来高で明確なトレンドが形成されたセクター。順張りフォローに適するが、押し目待ちが必要。 |
| **`通常`** | 双方が上位20%圏外 | ― | 平均的な推移。 |

## 3. 「⚡ 先行初動レーダー」4大兆候指標の解釈

*「価格が急騰する前の、水面下の出来高変化・引け値・下げ渋りを捉える」*

1. **① ステルス集積指数 (配点 35%)**:
   - $\text{当日セクター売買代金シェア倍率} \times \text{Median}(\text{CLV} \times \text{PriceSuppression})$
   - 価格が動いていない（前日比±0%付近）にもかかわらず、売買代金シェアが急増し、高値引け（CLV高）している銘柄群をスコアリング。
2. **② 出来高点火率 (配点 25%)**:
   - 直近5営業日以内に出来高枯渇（Volume Dry-Up）を記録した後に、当日出来高がトリム50日平均の1.5倍超に急増した陽線銘柄の比率。
3. **③ 市場逆行耐性比率 (配点 20%)**:
   - 地合い悪化時（市場下落日）において、前日比プラスまたは下落-1.5%以内かつ引け味良好（CLV $\ge 0.70$）で踏みとどまった相対的耐性銘柄の比率。
4. **④ 先導株先行アクション比率 (配点 20%)**:
   - 業種内の看板株（時価総額またはRS上位25%）のうち、前日以前20日最高値から $-3\% \sim +3\%$ のブレイク直前・直後に位置する銘柄比率。

## 4. 「📊 トレンド確認」3層11指標の解釈

*「資金流入がセクター全体に波及し、すでに上昇トレンドとして定着しているかを測定」*

- **Layer 1: 資金フロー (配点 40%)**: 売買代金シェア変化率/変化幅、規格化MFV、グループA/Dレシオ、グループCLV中央値。
- **Layer 2: 内部構造 (配点 35%)**: 騰落ブレッドス、等ウェイト vs 加重Spread、出来高急増陽線比率、新高値銘柄比率、トレンド同期率。
- **Layer 3: モメンタム (配点 25%)**: 超過RS（$\Delta$RS）、Stage 2ブレイク集中度。

## 5. ドリルダウンと実戦的な確認手順

1. **画面上部で視点を切り替える**:
   - **`[ ⚡ 先行初動レーダー ]`**: 動き出す前の初動兆候セクターを先行監視したい場合。
   - **`[ 📊 トレンド確認 ]`**: すでに出来上がっている強勢トレンドセクターを確認したい場合。
2. **進行段階バッジに着目**:
   - フィルターボタンで `[ ⚡📊 初動＋トレンド一致 ]` を押すことで、両方の基準で同時にトップ20%にランクインした合致セクターのみを即座に抽出可能。
3. **個別銘柄ドロワーの確認**:
   - 業種行をクリックするとサイドドロワーが展開。先行初動4指標のカードと、SEPAエンジン連動の「反発確認（前日高値上抜け）」「21EMA支持帯（調整中）」「50日線支持帯（調整中）」の3大押し目バッジを確認し、リスクリワードの高い具体的なエントリー候補を特定します。
