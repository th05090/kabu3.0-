# テーマ分析・スクリーニング機能 ユーザーガイド (AI抽出・動的検索)

## 概要
本システムは、企業の決算書（PDF）および四季報のテキストデータを統合的に解析し、高精度な事業要約とテーマ分類を自動で行う「ハイブリッド要約パイプライン」を実装しています。
従来の証券アプリのような固定的な「業種」にとらわれず、ユーザーが自分の言葉で入力したテーマ（例：「AIを活用した製造業」「円安メリットが大きい会社」など）で検索できる「動的テーマ検索機能」を提供します。

## 1. ハイブリッド要約パイプラインとは？

### 課題
企業の決算書だけをAIに読み込ませると、「当期純利益が増加した」という業績の説明は抽出できても、「そもそも何を売っている会社なのか（ビジネスモデル）」が抜けてしまうことが多々あります。
逆に四季報のテキストは事業内容が充実していますが、「任天堂向けが多い」「成長中」といった投資家向けの装飾語（ノイズ）が多く含まれるため、AI検索の邪魔になる問題がありました。

### 解決策（3ステップ抽出）
この問題を解決するため、以下の3段階のプロセスで最高品質の企業データを作成しています。

1. **四季報データの純化**: 四季報のテキストから取引先名や装飾語を取り除き、「純粋な機能的価値（誰に何を提供しているか）」のキーワードだけを抽出します。
2. **決算書からの事実抽出**: 決算書のPDFをベクトル検索（Qdrant）し、企業の「稼ぎ頭となる主力セグメント」とその具体的な事業内容を抽出します。
3. **最終要約の生成**: 上記2つの情報を統合し、AI（Gemma）が「30〜50文字のコンパクトな1文要約」と「主幹テーマ」を決定します。

## 2. GICSを用いた高精度な主幹テーマ分類
主幹テーマ（大分類）の決定においては、AIの「気まぐれ」による分類エラー（ハルシネーション）を防ぐため、**ハイブリッド検索（RRF）と2段階LLM推論を組み合わせた確定アルゴリズム**を採用しています。

1. **候補の抽出 (ハイブリッド検索)**: まず、システム内に保存されたGICS（世界産業分類基準）の細分類（全158種）に対して、企業のベクトル情報（Dense）とキーワード情報（Sparse）の両面から検索を行い、上位10のカテゴリ候補を抽出します。
2. **Stage 1 (LLMによる絞り込み)**: 「最優先判定基準：メイン事業セクションの売上規模および事業内容に最も合致するテーマを必ず選ぶこと」という強いルールのもとで、AI（Gemma3）に上位10候補から3つを選ばせます。
3. **Stage 2 (最終決定)**: 絞り込まれた3つの候補のみを使って再度AIに推論させ、「最も実態に近い1つのテーマ」を厳密に決定させます。
これにより、「特定の単語に引っ張られて、売上規模の小さい事業を主幹テーマだと勘違いする」というAI特有のエラーを排除し、ブレのない完璧なセクター分類が保証されています。

## 3. 動的テーマ検索 (ハイブリッド Semantic Search) の使い方
固定の主幹テーマ（例：「情報通信技術」など）とは別に、自由な自然言語による**「動的テーマ検索」**が利用可能です。

UIの検索窓に、あなたが思い浮かべた投資テーマを自然な日本語で自由に入力してください。
* 検索例1: `「クラウドを利用したDX支援コンサルティング」`
* 検索例2: `「インバウンド需要の恩恵を受ける小売業」`
* 検索例3: `「AIや画像認識を用いた工場自動化・外観検査」`

### 3.1 AIによるキーワード拡張とユーザー編集
検索を実行すると、まずAI（Gemma3モデル）があなたの入力した文章を解析し、検索に必要な**周辺キーワード（同義語や関連技術など）を自動で展開**して画面のキーワードバーに表示します。
このキーワードは手動で追加・削除（「×」ボタン）することが可能です。「このキーワードは少し違うな」と思ったら削除することで、検索精度を自在にコントロールできます。

### 3.2 ハイブリッド検索とLocal RRFアルゴリズム
本システムは単なるベクトル検索ではなく、2つの強力な検索エンジンを組み合わせた**ハイブリッド検索**を実行します。

1. **ベクトル検索 (Dense Search)**: Qdrantを使用し、入力された自然言語の意味（文脈）を理解して、キーワードが一致していなくても意味が近い銘柄を探し出します。
2. **全文キーワード検索 (Sparse Search)**: SQLiteのFTS5（日本語全文検索エンジン）を使用し、展開されたキーワードが企業の事業要約に正確に含まれているか（BM25スコア）を計算します。
3. **Local RRF (Reciprocal Rank Fusion)**: 両者の検索順位を `1/(60+Dense順位) + 1/(60+Sparse順位)` という計算式で融合させます。
   これにより、「意味は合っているがキーワードが入っていない銘柄」と「キーワードは合っているが意味が違う銘柄（ノイズ）」を自動で補正し、**文脈もキーワードも完璧に合致する大本命の銘柄**だけをランキングの最上位に押し上げます。
